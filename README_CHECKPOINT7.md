# Checkpoint 7

## Про что этот этап

На 7-м чекпоинте проект был доведён до состояния рабочего Telegram-бота для персонализированных рекомендаций новостей.

В отличие от ранней версии репозитория, здесь уже есть не только идея и пайплайны, но и:
- живой бот с онбордингом;
- ML-классификация новостей по темам;
- персональная лента и дайджест;
- импорт пользовательских Telegram-каналов;
- автоматическое обновление новостного корпуса;
- улучшенный UX кнопочного меню и карточек новостей.

---

## Что реализовано

### 1. Telegram-бот рекомендаций

Бот находится в [bot](/C:/Users/Yaroslav/Documents/aggregator-bot/bot) и умеет:
- собирать стартовый профиль пользователя через онбординг;
- предлагать темы и любимые источники;
- принимать пользовательские Telegram-каналы;
- формировать персональную новостную ленту;
- собирать короткий дайджест;
- искать новости по текстовому запросу;
- учитывать лайки, дизлайки и историю показов.

Основные файлы:
- [telegram_bot.py](/C:/Users/Yaroslav/Documents/aggregator-bot/bot/telegram_bot.py)
- [recommender.py](/C:/Users/Yaroslav/Documents/aggregator-bot/bot/recommender.py)
- [storage.py](/C:/Users/Yaroslav/Documents/aggregator-bot/bot/storage.py)
- [channel_importer.py](/C:/Users/Yaroslav/Documents/aggregator-bot/bot/channel_importer.py)

### 2. Персонализация

Бот использует профиль пользователя:
- выбранные темы;
- любимые источники;
- свои каналы;
- лайки и дизлайки;
- уже показанные новости.

Рекомендации строятся не просто по каналу, а по тематике, confidence модели, свежести новости и пользовательским предпочтениям.

### 3. Улучшенный UX

В боте реализован кнопочный интерфейс.

Главное меню специально упрощено под реальное использование в Telegram:
- `🗞 Дайджест`
- `📰 Моя лента`
- `🔎 Найти новости`
- `☰ Ещё`

Дополнительные действия вынесены в отдельное меню, чтобы клавиатура не занимала полэкрана.

Карточки новостей тоже были переработаны:
- убран сырой markdown и служебный мусор;
- выделен нормальный заголовок;
- появилась компактная строка `тема • источник • дата`;
- добавлено объяснение, почему новость показана пользователю;
- оставлена ссылка `Подробнее`.

### 4. Группировка и антидубли

В recommendation-слое добавлена дедупликация близких новостей.

Бот старается:
- не показывать подряд несколько почти одинаковых постов;
- сохранять разнообразие источников;
- группировать часть похожих материалов как одно событие.

### 5. Автоматический импорт пользовательских каналов

Если пользователь добавляет свой канал:
- бот сохраняет его в профиль;
- пытается импортировать его через Telethon;
- при успешном импорте включает новые новости в общий корпус рекомендаций.

Это позволяет строить персонализированную ленту не только по заранее заготовленным источникам, но и по каналам самого пользователя.

### 6. Автоматическое обновление новостей

Сделан отдельный refresh-pipeline:
- [refresh_pipeline.py](/C:/Users/Yaroslav/Documents/aggregator-bot/bot/refresh_pipeline.py)
- [run_refresh.ps1](/C:/Users/Yaroslav/Documents/aggregator-bot/bot/run_refresh.ps1)

Что он делает:
- обновляет базовые Telegram-каналы;
- обновляет пользовательские каналы;
- пишет статус в [refresh_status.json](/C:/Users/Yaroslav/Documents/aggregator-bot/bot_data/refresh_status.json);
- работает по расписанию через Windows Scheduled Task.

Логика обновления:
- быстрые новостные каналы обновляются чаще;
- медленные тематические каналы реже;
- пользовательские каналы тоже обновляются автоматически.

Бот умеет подхватывать обновлённый корпус без ручного перезапуска.

## Как запустить

### Telegram-бот

Из корня репозитория:

```bash
py -m bot.telegram_bot
```

Нужны переменные окружения в `.env`:

```env
TELEGRAM_BOT_TOKEN=...
API_ID=...
API_HASH=...
SESSION_NAME=...
```

### Refresh-pipeline

Разовый запуск:

```bash
py -m bot.refresh_pipeline
```

Windows wrapper:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\bot\run_refresh.ps1
```

### FastAPI-сервис

```bash
docker compose build
docker compose up
```

После запуска документация доступна по адресу:

- [http://localhost:8080/docs](http://localhost:8080/docs)
