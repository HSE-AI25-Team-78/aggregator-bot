# Telegram News Recommendation Bot

Этот бот делает MVP рекомендательной системы на новостях из `data/all_channels_combined.csv`.

Как это работает:
- при первом запуске бот проводит onboarding;
- пользователь выбирает интересы через мультивыбор;
- затем выбирает любимые источники;
- при желании прямо на этом же шаге добавляет свои Telegram-каналы;
- после этого бот строит стартовую персональную ленту;
- дальше рекомендации уточняются по лайкам, дизлайкам и поисковым запросам.

## Переменные окружения

- `TELEGRAM_BOT_TOKEN` - токен Telegram-бота
- `NEWS_DATASET_PATH` - путь к CSV с новостями, по умолчанию `data/all_channels_combined.csv`
- `BOT_STORAGE_PATH` - путь к JSON с профилями пользователей, по умолчанию `bot_data/user_profiles.json`

## Запуск

Из корня репозитория:

```bash
py -m bot.telegram_bot
```

Если используется окружение проекта, можно запускать через него.

## Интерфейс

- `📰 Моя лента` - персональная подборка
- `🔎 Найти новости` - поиск похожих новостей по текстовому запросу
- `⚙️ Настроить интересы` - повторный запуск onboarding
- `🧾 Мой профиль` - просмотр пользовательского профиля
- `🧹 Сбросить профиль` - очистить накопленные предпочтения
- `ℹ️ Помощь` - подсказка по сценарию

Slash-команды остаются как резервный способ управления, но основной UX кнопочный.

## Сценарий для чекпоинта

1. Пользователь запускает бота.
2. Выбирает интересы.
3. На втором шаге выбирает любимые источники и при желании добавляет свои Telegram-каналы.
4. Получает стартовую персональную ленту.
5. Ставит лайки на интересные карточки.
6. Нажимает `📰 Моя лента` и видит более точные рекомендации.
7. Нажимает `🔎 Найти новости`, пишет `новости про экономику` и получает релевантные материалы.
