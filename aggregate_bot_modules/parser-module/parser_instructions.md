# 📡 Инструкция по работе с Telegram‑парсером

Этот модуль отвечает за **сбор данных из Telegram‑каналов**, которые затем используются в ML‑пайплайне проекта (предобработка → разбиение → обучение моделей → визуализации).  
Парсер выгружает посты, формирует датасет `raw_posts_labeled.csv` и сохраняет его в директорию `data/`.

---

# 1. 📦 Подготовка окружения

## Установка зависимостей

```bash
pip install -r requirements.txt
```

Парсер основан на библиотеке **Telethon**.

## Создание файла `.env`

В корне проекта создайте файл `.env` и добавьте свои данные:

```
API_ID=123456
API_HASH=your_api_hash_here
SESSION_NAME=tg_session
TG_PHONE=+7XXXXXXXXXX
# TG_2FA=пароль_2FA   # если включена двухфакторная авторизация
```

API‑ключи можно получить на https://my.telegram.org → *API development tools*.

---

# 2. ▶️ Запуск базового парсинга канала

```bash
python parser.py --channel @rbc_news --limit 1000
```

Первый запуск потребует:
- код из Telegram,
- пароль 2FA (если включён).

После выполнения появится CSV:

```
data/rbc_news.csv
```

---

# 3. ⚙️ Параметры запуска

| Аргумент    | Описание                          | Пример                         |
|-------------|------------------------------------|--------------------------------|
| `--channel` | username Telegram‑канала           | `--channel @rbc_news`          |
| `--limit`   | ограничение по сообщениям          | `--limit 2000`                 |
| `--out`     | путь к CSV (опционально)           | `--out data/custom.csv`        |
| `--phone`   | номер телефона                     | `--phone +79995553322`         |
| `--two_fa`  | пароль двухфакторной авторизации   | `--two_fa myPassword123`       |

Пример полного вызова:

```bash
python parser.py --channel @tass_agency --limit 500 --out data/tass.csv
```

---

# 4. 🤖 Автоматический сбор нескольких каналов

Для проекта используется скрипт:

```
parser-module/build_dataset.py
```

Он:

1. подключается к Telegram;
2. по списку каналов из `channels_config.py` скачивает посты;
3. пропускает каналы, которые:
   - не существуют,
   - приватные,
   - пустые;
4. объединяет всё в единый датасет;
5. сохраняет:

```
data/raw_posts_labeled.csv
```

Запуск:

```bash
python build_dataset.py
```

---

# 5.  Особенности работы и улучшения

Мы добавили:

##  Обработку ошибок
- пропуск недоступных/несуществующих каналов;
- сообщения `Нет сообщений, пропускаем`;

##  Устойчивость к падениям
- try/except вокруг каждого канала;
- предотвращение крэша при неправильных username.

##  Интеграцию с ML‑пайплайном
Теперь результат парсера является входом для:

- `ml/preprocess.py` — очистка текстов  
- `ml/dataset_split.py` — train/val/test  
- `ml/run_all.py` — автоматический ML‑конвейер

Парсер теперь — **первый шаг общего конвейера**.

---

# 6. 📌 Что делать после парсинга?

После того как `raw_posts_labeled.csv` готов:

1. перейти в папку `aggregator-bot`;
2. запустить полный ML‑пайплайн командой:

```bash
python -m ml.run_all
```

Этот скрипт:
- очистит данные,
- соберёт train/val/test,
- обучит baseline‑модели,
- выполнит тюнинг,
- обучит финальную модель,
- нарисует все визуализации.
